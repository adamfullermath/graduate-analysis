    Section 3.2 Calculating Hausdorff Dimension

    In this section we will give some examples of calculating the Hausdorff dimension. We begin with a simple, but important example: a unit interval in \(\bR^n\)
    🔗

    Example 3.2.1.

    Let \(E\) be a unit interval in \(\bR^n\text{.}\) That is, let
    \begin{equation*} E = \underbrace{[0,1]\times \ldots \times [0,1]}_{n \text{ times}}. \end{equation*}
    For \(k \gt 0\text{,}\) subdivide each interval \([0,1]\) in \(E\) into \(k\) equal length pieces, so that \(E\) is divided into \(k^n\) smaller intervals. That is,
    \begin{equation*} E = \bigcup_{i_1=0}^{k-1}\ldots\bigcup_{i_n=0}^{k-1} \left[\frac{i_1}{k},\frac{i_1 + 1}{k}\right]\times \ldots \times \left[\frac{i_n}{k},\frac{i_n + 1}{k}\right]. \end{equation*}
    Each of these subintervals has diameter \(\frac{\sqrt{n}}{k}\text{.}\) Take \(0 \lt \delta \lt 1\) and choose \(K \gt 0\) such that \(\frac{\sqrt{n}}{k} \lt \delta\) when \(k \geq K\text{.}\) If \(k \geq K\text{,}\) then
    \begin{equation*} H_{n,\delta}(E) \leq \sum_{j=1}^{k^n}\left(\frac{\sqrt{n}}{k}\right)^n = n^{n/2}. \end{equation*}
    Hence \(H_n(E)\leq n^{n/2}\lt \infty.\) Thus, by Proposition 3.1.6, \(\dim_H(E)\leq n.\)
    🔗
    Let \(C_n\) be the volume of the unit ball in \(\bR^n\text{.}\) That is, if \(D_n = \{ x \in \bR^n\colon \|x\|_2 \leq 1\},\)
    \begin{equation*} C_n = m_n(D_n), \end{equation*}
    where \(m_n\) is the Lebesgue measure on \(\bR^n.\) Now, if \(D\) is a ball anywhere in \(\bR^n\) with diameter \(\delta\gt 0\text{,}\) then \(m_n(D) = C_n\delta^n\) by Proposition 1.2.7 and Theorem 1.3.6. Thus, if \(B \subseteq \bR^n\) is bounded, there is a ball \(D\subseteq \bR^n\) with \(B \subseteq D\) with \(m_n(D) = C_n \diam(B)^n.\)
    🔗
    Let \(\delta \gt 0\) and let \(\{B_j\}_{j=1}^\infty\) be sets with \(E \subseteq \bigcup_{j=1}^\infty B_j\) and \(\diam(B_j)=\lt \delta.\) By the above argument, there are balls \(D_j \subseteq \bR^n\text{,}\) with \(B_j \subseteq D_j\) and \(\diam(D_j)= \diam(B_j)\) for each \(j.\) Thus,
    \begin{align*} 1 = m_n(E) \amp \leq \sum_{j=1}^\infty m_n(D_j) \\ \amp = C_n \sum_{j=1}^\infty \diam(B_j)^n. \end{align*}
    As this holds for any such choice \(\{B_j\}_{j=1}^\infty\) of cover of \(E\text{,}\) it follows that \(0\lt m_n(E) \leq C_n H_n(E).\) Thus, by Proposition 3.1.6, \(\dim_H(E)\geq n\text{.}\) It follows that \(\dim_H(E) = n.\)
    🔗
    🔗
    Example 3.2.1 has wider reaching consequences than just the interval \(E\text{.}\)
    🔗

    Theorem 3.2.2.

    There is a constant \(0 \lt \alpha_n \lt \infty\text{,}\) such that the Hausdorff measure \(H_n\) on \(\bR^n\) satisfies, \(m_n = \alpha H_n.\)
    🔗
    🔗

    Proof.

    The Hausdorff measure \(H_n\) on \(\bR^n\) is a non-zero Borel measure by Example 3.2.1. Each Hausdorff measure is clearly invariant under addition, i.e. \(H_p(E) = H_p(E+x)\) for all \(E \subseteq \bR^n\) and \(x \in \bR^n.\) Thus, \(H_n\) is a Haar measure on \(\bR^n\text{.}\) By Theorem 2.2.14, there is a non-zero scalar such that \(m_n = \alpha H_n.\)
    🔗
    🔗

    Corollary 3.2.3.

    If \(E \subseteq \bR^n\) is a Borel set and \(m_n(E)\lt \infty\text{,}\) then \(\dim_H(E)\leq n\text{.}\) In particular, if \(0\lt m_n(E) \lt \infty\text{,}\) then \(\dim_H(E)=n\text{.}\)
    🔗
    🔗
    In the next example we give the Hausdorff measure of a curve in \(\bR^2\) defined by a continuously differentiable function. Such a curve will have Lebesgue measure \(0\text{.}\)
    🔗

    Example 3.2.4.

    Let \(f \colon [0,1] \rightarrow \bR\) be a continuous, non-constant function with \(f'\) defined and bounded on \((0,1)\) by \(\lambda \gt 0.\) Let \(C = \{(t,f(t)) \colon 0 \leq t \leq 1\}\text{.}\) We want to calculate the Huasdorff dimension of the curve \(C\text{.}\) Since \(C\subseteq \bR^2\text{,}\) Corollary 3.2.3 shows that \(2\) is an upper bound for \(\dim_H C.\)
    🔗
    Note that \(f\) is absolutely continuous, and hence of bounded variation, by Exercise I.7.5.6. Take \(0\leq a \lt b \leq 1\) and let \(a=x_0\lt x_2 \lt \ldots \lt x_n =b\) be a partition of \([a,b].\) Then,
    \begin{align*} \sum_{k=1}^n |f(x_i)-f(x_{i-1})| \amp = \sum_{k=1}^n \frac{|f(x_i)-f(x_{i-1})|}{|x_i - x_{i-1}|}|x_i - x_{i-1}| \\ \amp \leq \lambda \sum_{i=1}^n |x_i - x_{i-1}| \\ \amp = \lambda(a-b) \\ \amp \leq \lambda \|(a,f(a)) - (b,f(b))\|_2, \end{align*}
    where the first inequality follow from the Mean Value Theorem. Thus, if \(B = \{(t,f(t)) \colon a \leq t \leq b\}\text{,}\) then
    \begin{equation*} TV(f|_{[a,b]}) \leq \lambda \diam(B), \end{equation*}
    where \(TV(f|_{[a,b]})\) is the total variation of \(f\) restricted to \([a,b]\text{.}\) Let \(|\nu|\) be the Borel measure on \([0,1]\) induced by \(x \mapsto TV(f|_{[0,x]})\text{.}\) That is, if \(\nu\) is the Borel signed-measure induced by \(f\text{,}\) then \(|\nu|\) is the measure of total variation of \(\nu\text{.}\) Define a Borel measure \(\mu\) on \(C\) by \(\mu(B) = |\nu|(\{t \colon (t,f(t))\in B\})\text{.}\) Extend \(\mu\) to a Borel measure on \(\bR^2\) by setting \(\mu(B) = \mu(B \cap C)\) for Borel sets \(B \cap C.\) It follows from the above inequality that for Borel sets \(B \subseteq \bR^2\text{,}\)
    \begin{equation*} \mu(B) \leq \lambda \diam(B). \end{equation*}
    Let \(\{B_k\}_{k=1}^\infty\) be a cover of \(C\) where each \(\diam(B_k)\lt \delta\) for some \(\delta\text{.}\) We can take the closure of each \(B_k\) without changing the diameter of \(B_k\text{.}\) Thus, we can assume each \(B_k\) is a Borel set. Hence
    \begin{equation*} 0\lt TV(f) = \mu(C) \leq \sum_{k=1}^\infty \mu(B_k) \leq \lambda \sum_{k=1}^\infty \diam(B_k). \end{equation*}
    Hence \(0\lt H_{1,\delta}(C)\) for each \(\delta\gt 0\text{.}\) Therefore \(\dim_H C\geq 1.\)
    🔗
    Let \(L\) be the arc length of \(C\text{.}\) Since \(f\) is of bounded variation, \(L\) is finite by Exercise I.4.3.11. For each \(n\text{,}\) we can choose \(0=x_0\lt \dots \lt x_n=1\) such that the arc length of \(f\) over \([x_{i-1},x_i]\) is \(L/n.\) Let \(B_i = \{(t,f(t)) \colon x_{i-1}\leq t \leq x_i\}\) for \(i=1,\ldots,n.\) Then
    \begin{equation*} \sum_{i=1}^n \diam(B_i) \leq n \frac{L}{n} = L. \end{equation*}
    It follows that \(H_1(C) \leq L\text{,}\) and hence \(\dim_H C \leq 1.\) Therefore \(\dim_H C =1.\)
    🔗
    🔗
    Theorem 3.2.2 justifies, somewhat, the use of the word dimension in Hausdorff dimension. Lebesgue measure on \(\bR\) generalizes length; Lebesgue measure on \(\bR^2\) generalizes area; Lebesgue measure on \(\bR^3\) generalizes volume; et cetera. Thus, if a set \(E \subseteq \bR^n\) can be said to have length/area/volume in \(\bR^n\text{,}\) then \(E\) has (Hausdorff) dimension \(n\text{.}\) Further evidence that Hausdorff dimension is consistent with intuition on what dimension should mean is given in Example 3.2.4, Exercise 3.3.1, and Exercise 3.3.2. If these were the only application of Hausdorff measure, then Hausdorff measure would not be of much interest. The interesting examples are when a set \(E \subseteq \bR^n\) has Lebesgue measure \(0\text{,}\) and \(E \not\subseteq V\) for any proper subspace \(V \subseteq \bR^n\text{,}\) but is still sufficiently complex to have non-zero Hausdorff dimension. The first example of a complicated, Lebesgue measure \(0\) set we saw was the Cantor set, Example I.3.2.3.
    🔗

    Example 3.2.5.

    Let \(C \subseteq [0,1]\) be the Cantor set, and let \(\{C_n\}_{n=0}^\infty\) be the closed sets used to construct the Cantor set, as described in Example I.3.2.3. That is, \(C_0 = [0,1]\text{.}\) \(C_1 = [0,1/3] \cup [1/3,1]\text{,}\) and so on (see Figure I.3.2.4), and \(C = \bigcap_{n=0}^\infty C_n.\) For each \(n\text{,}\) \(C \subseteq C_n\) and \(C_n\) is a disjoint union of \(2^n\) intervals of diameter \(\frac{1}{3^n}\text{.}\) Take \(\delta \gt 0\text{,}\) and \(N \geq 0\) such that \(\frac{1}{3^n}\) for all \(n \geq N\text{.}\) For \(p \gt 0\text{,}\) we thus have,
    \begin{equation*} H_{p,\delta}(C) \leq 2^n \left(\frac{1}{3^n}\right)^p \end{equation*}
    for all \(n \geq N\text{.}\) Let \(p = \log_3(2)\text{.}\) Then, for all \(n\text{,}\)
    \begin{equation*} \left(\frac{1}{3^n}\right)^p = \frac{1}{2^n}. \end{equation*}
    Hence, if \(p = \log_3(2)\text{,}\) \(H_{p,\delta}(C) \leq 1,\) and therefore \(H_p(C)\leq 1.\) Hence, \(\dim_H(C) \leq p.\)
    🔗
    Let \(\phi\) be the Cantor-Lebesgue function on \([0,1]\text{,}\) as described in Example I.3.2.5. Extend \(\phi\) to all of \(\bR\) by setting \(\phi(x) = 1\) if \(x \geq 1\text{,}\) and \(\phi(x) = 0\) if \(x \leq 0\text{.}\) Let \(\mu\) be the Borel measure on \(\bR\) induced by \(\phi\text{.}\) That is, \(\mu\) is the Borel measure induced by the premeasure \(\mu((c,d]) = \phi(d) - \phi(c). \) By Exercise I.3.4.10, \(\mu\) is singular with respect to Lebesgue measure \(m\text{,}\) and \(\mu(C) = \mu(\bR) = 1.\) Take \(\delta \lt \frac{1}{3}\text{.}\) If \(B \subseteq \bR\) and \(\diam(B)\lt \delta\text{,}\) then there is an \(n \geq 1\) such that
    \begin{equation*} \frac{1}{3^{n+1}} \leq \diam(B) \lt \frac{1}{3^n}. \end{equation*}
    Since \(\diam(B) \lt \frac{1}{3^n}\text{,}\) \(B\) intersects at most \(1\) interval in \([0,1]\backslash C_n\text{.}\) Thus, \(\mu(B) \leq \frac{1}{2^n}.\) Hence, with \(p = \log_3(2)\text{,}\)
    \begin{align*} (\diam(B))^p \amp\geq \left(\frac{1}{3^{n+1}}\right)^p = \frac{1}{2^{n+1}} \\ \amp = \frac{1}{2}\cdot \frac{1}{2^n}\geq \frac{1}{2}\mu(B) \end{align*}
    Now, suppose \(C \subseteq \bigcup_{k=1}^\infty B_k\) where each \(B_k \subseteq \bR\) and \(\diam(B_k)\lt \delta\text{.}\) Then, by the above calculation,
    \begin{equation*} 1 = \mu(C) \leq \sum_{k=1}^\infty \mu(B_k) \leq 2 \sum_{k=1}^\infty \diam(B_k)^p. \end{equation*}
    Taking an infimum over all such families \(\{B_k\}_{k=1}^\infty\) and taking the limit as \(\delta \rightarrow 0\text{,}\) we see that
    \begin{equation*} 1 \leq H_{p}(C) \end{equation*}
    and so \(\dim_H(C)\geq p. \) We have thus shown that
    \begin{equation*} \dim_H(C) = \log_3(2) = \frac{\ln(2)}{\ln(3)}\approx 0.631. \end{equation*}
    🔗
    🔗
    It should be noted that the line of argument used in Example 3.2.1, Example 3.2.4, and Example 3.2.5 is the same: we get an upper bound for \(\dim_H(E)\) by finding suitable covers of \(E\text{,}\) and we get a lower bound for \(\dim_H(E)\) by comparing \(H_p\) to a measure on \(E\text{.}\) In Example 3.2.1 we used the Lebesgue measure \(m_n\text{;}\) in Example 3.2.4 we used the measure induced by the function of total variation; in Example 3.2.5 we used the Borel measure induced by the Cantor-Lebesgue function. If we want to apply this method to calculate the Hausdorff dimension of other sets, we will need to find a suitable measure for each set. If and how we can do this is not at all clear. However, we will see in Theorem 3.2.9, that if a set \(E\) is suitably symmetric we can always find a suitable measure.

    Definition 3.2.6.

    A map \(S \colon \bR^n \rightarrow \bR^n\) is a similitude with scaling factor \(r\) if there is a orthogonal map \(U\) on \(\bR^n\text{,}\) a vector \(b \in \bR^n\text{,}\) and a scalar \(r \gt 0\) such that
    \begin{equation*} S(x) = rU(x) + b \end{equation*}
    for all \(x \in \bR^n\text{.}\)

    Let \(S=(S_1,\ldots,S_m)\) be a \(m\)-tuple of similitudes on \(\bR^n\text{.}\) For \(E \subseteq \bR^n\text{,}\) let \(S(E) = \bigcup_{k=1}^m S_k(E).\) We say that \(E \subseteq \bR^n\) is invariant under the similtudes \(S\) if \(E=S(E).\)
    🔗
    🔗

    Definition 3.2.7.

    Let \(S = (S_1,\ldots,S_m)\) be a family of similitudes on \(\bR^n\text{.}\) A non-empty open set \(U \subseteq \bR^n\) is a separating set for \(S\) if
    \begin{equation*} S(U) \subseteq U,\ \text{ and } \{S_k(U)\}_{k=1}^m \text{ are pairwise disjoint}. \end{equation*}
    🔗
    🔗
    When \(S=(S_1,\ldots,S_m)\) is a tuple of similitudes and \(k \geq 0\) we define \(S^k(E)\) for \(E \subseteq \bR^n\) by
    \begin{equation*} S^{0}(E) = E,\ S^1(E)=S(E),\ \text{ and } S^k(E) = S(S^{k-1}(E)). \end{equation*}

    Example 3.2.8.

    Define similitudes \(S_1\) and \(S_2\) on \(\bR\) (both with scaling factor \(\frac{1}{3}\)) by
    \begin{equation*} S_1(x) = \frac{1}{3}x \text{ and } S_2(x) = \frac{1}{3}x + \frac{2}{3}. \end{equation*}
    Let \(C \subseteq [0,1]\) be the Cantor set, as in Example I.3.2.3. Then \(S_1(C) = C \cap [0,\frac{1}{3}]\) and \(S_2(C) = C\cap [\frac{2}{3},1].\) Thus, \(C\) is invariant under \(S =(S_1,S_2).\) Further, if \(V\) is the open inverval \((0,1)\text{,}\) then \(V\) is a separating set for \(S\text{.}\)
    🔗
    Note that we can construct \(C\) using \(V\) and \(S\text{.}\) Indeed, if \(\overline{V}\) is the closure on \(V\) (i.e. \(\overline{V} = [0,1]\)) then
    \begin{align*} S(\overline{V}) \amp= \left[0,\frac{1}{3}\right] \cup \left[\frac{2}{3},1\right] = C_1, \\ S^2(\overline{V}) \amp= C_2,\\ \amp\vdots \\ S^k(\overline{V}) \amp= C_k \end{align*}
    where \(C_1,\ldots,C_k\) are defined as in Example I.3.2.3. Thus,
    \begin{equation*} C = \bigcap_{k=1}^\infty S^k(\overline{V}). \end{equation*}
