    Section 6.3 Lebesgue integration and Riemann integration

    In Chapter 1 we argued for the need of a form of integration more robust than Riemann integration. Have we achieved that? We will see that for integrals of bounded functions over closed intervals \([a,b]\) that the answer is yes.
    🔗
    When \(f\) is Riemann integrable on an interval \([a,b]\) we denote the Riemann integral of \(f\) by \(\mathrm{R}{\int}_a^b f\text{.}\) We first establish precisely, what functions are Riemann integrable.
    🔗
    Let \([a,b]\) be a closed interval in \(\mathbb{R}\text{,}\) and let \(f \colon [a,b] \rightarrow \mathbb{R}\) be a bounded function. Let \(P = \{x_0, x_1, \ldots, x_n\}\) be a partition of \([a,b]\text{,}\) where
    \begin{equation*} a = x_0 < x_1 < \ldots < x_n = b. \end{equation*}
    We define \(O(f,P)\) as
    \begin{equation*} O(f,P) = \sum_{k=1}^n \sup_{x,y \in [x_{k-1},x_k]}|f(x) - f(y)|(x_k - x_{k-1}) \end{equation*}
    The function \(f\) is Riemann integrable if for all \(\varepsilon > 0\) there exists a partition \(P\) of \([a,b]\) such that \(O(f,P)< \varepsilon\text{.}\)
     1 
    You may have seen other definitions of Riemann integrable. Can you prove that your definition of Riemann integrable is equivalent to the definition given here?
    🔗

    Theorem 6.3.1.

    Let \(f\) be a bounded function on the closed interval \([a,b]\text{,}\) and let \(D = \{x \in [a,b] \colon f \text{ is not continuous at }x\}\text{.}\) Then \(f\) is Riemann integrable if and only if \(D\) has Lebesgue measure \(0\text{.}\)
    🔗
    🔗

    Proof.

    Suppose that \(f\) is Riemann integrable. Take \(x \in [a,b]\text{.}\) The function \(f\) is not continuous at \(x\text{,}\) if there exists \(\varepsilon\) such that for all \(\delta >0\) there exists \(y \in (x-\delta,x + \delta)\cap [a,b]\) such that \(|f(x)-f(y)|\geq \varepsilon\text{.}\) Thus, if we set
    \begin{equation*} D_\eta = \{ x\in [a,b] \colon \forall \delta >0 \exists y\in (x-\delta,x+\delta) \text{ such that }|f(x)-f(y)|\geq\eta\}, \end{equation*}
    then
    \begin{equation*} D = \bigcup_{\eta >0} D_\eta. \end{equation*}
    That that, if \(\eta_2 > \eta_1 > 0\text{,}\) then \(D_{\eta_2} \subseteq D_{\eta_1}.\) Thus, we can write \(D\) as a countable union
    \begin{equation*} D = \bigcup_{n=1}^\infty D_{\frac{1}{n}}. \end{equation*}
    Fix \(\eta >0\text{.}\) We will show that \(m^*(D_\eta) = 0\text{.}\) Take any \(\varepsilon > 0\text{.}\) Since \(f\) is Riemann integrable, there exists a partition
    \begin{equation*} P = \{a=x_0 < x_1 < \ldots < x_n = b\} \end{equation*}
    such that \(O(f,P)< \varepsilon\text{.}\) Let \(\Lambda = \{k \colon D_\eta \cap [x_{k-1},x_k] \neq \emptyset\}.\) Then
    \begin{equation*} \begin{aligned} \eta\sum_{k \in \Lambda}(x_k - x_{k-1}) &\leq \sum_{k\in \Lambda} \sup_{x,y \in [x_{k-1},x_k]}|f(x)-f(y)|\\ &\leq \sum_{k=1}^n \sup_{x,y \in [x_{k-1},x_k]}|f(x)-f(y)|\\ &= O(f,P)< \varepsilon. \end{aligned} \end{equation*}
    Since \(D_\eta \subseteq \bigcup_{k \in \Lambda} [x_{k-1},x_k]\) it follows that
    \begin{equation*} m^*(D_\eta) < \frac{\varepsilon}{\eta}. \end{equation*}
    The above inequality holds for all \(\varepsilon>0\text{,}\) and so \(m^*(D_\eta) = 0\text{.}\) It follows that \(D_\eta\) is Lebesgue measurable and \(m(D_\eta) = 0\) (see Exercise 2.4.12). We have now that
    \begin{equation*} m^*(D) \leq \sum_{n=1}^\infty m^*(D_{\frac{1}{n}}) = 0 \end{equation*}
    and so \(D\) is also Lebesgue measurable with \(m(D) = 0\text{.}\)
    🔗
    Suppose now that \(D\) has Lebesgue measure \(0\text{.}\) Given \(\varepsilon > 0\text{,}\) there exists open intervals \(\{I_k\}_{k=1}^\infty\) such that
    \begin{equation*} m(D) \leq \sum_{k=1}^\infty \ell(I_k) < \varepsilon. \end{equation*}
    Let \(U = \bigcup_{k=1}^\infty I_k\) and \(K = [a,b] \backslash U\text{.}\) The set \(U\) is a union of open intervals, and so \(U\) is open in \(\mathbb{R}\text{.}\) Thus, \(K\) is closed. As \(K \subseteq [a,b]\text{,}\) \(K\) is both closed and bounded, and so \(K\) is compact by the Heine-Borel Theorem, Theorem B.2.15.
    🔗
    The function \(f\) is continuous on \([a,b]\backslash D\text{.}\)
    🔗
    Hence, for each \(x \in [a,b]\backslash D\) there exists \(\delta_x>0\) such that, for if \(y \in [a,b]\) and \(|x-y|<\delta_x\) then \(|f(x)-f(y)|<\varepsilon\text{.}\) The open intervals \(\{(x-\frac{\delta_x}{2}, x+\frac{\delta_x}{2})\}_{x\in K}\) form an open cover of \(K\text{.}\) Since \(K\) is compact, there are is a finite set \(x_1,x_2,\ldots,x_n \in K\) such that
    \begin{equation*} K \subseteq \bigcup_{k=1}^n (x_i - \frac{\delta_{x_i}}{2}, x_i + \frac{\delta_{x_i}}{2}). \end{equation*}
    Let
    \begin{equation*} P = \{a,b\} \cup (\{x_i-\frac{\delta_{x_i}}{2}, x_i + \frac{\delta_{x_i}}{2} \} \colon i = 1,\ldots,n\} \cap [a,b]). \end{equation*}
    The set \(P\) is finite, and contains both \(a\) and \(b\text{,}\) we can thus order \(P\) and view \(P\) as a partition of \([a,b]\text{.}\) Let the ordered elements of \(P\) be denoted by
    \begin{equation*} \{a=y_0 < y_1 <\ldots < y_m = b\}. \end{equation*}
    Note that, if there are \(i\) and \(j\) such that \((x_i - \frac{\delta_{x_i}}{2}, x_i + \frac{\delta_{x_i}}{2}) \cap (y_{j-1},y_j) \neq \emptyset\) then \([y_{j-1},y_j] \subseteq [x_i - \frac{\delta_{x_i}}{2}, x_i + \frac{\delta_{x_i}}{2}] \subseteq (x_i -\delta_{x_i}, x_i + \delta_{x_i})\text{.}\) Let
    \begin{equation*} A = \{ j \colon \exists \ i \text{ such that }[y_{j-1},y_j] \subseteq [x_i-\frac{\delta_{x_i}}{2}, x_i + \frac{\delta_{x_i}}{2}]\} \end{equation*}
    and
    \begin{equation*} B = \{ j \colon [y_{j-1},y_j] \cap (x_i-\frac{\delta_{x_i}}{2},x_i+\frac{\delta_{x_i}}{2}) = \emptyset \text{ for all }i\}. \end{equation*}
    Note, if \(j \in A\text{,}\) and \(x,y \in [y_{i-1},y_i]\) then
    \begin{equation*} |f(x)-f(y)|\leq |f(x) - f(x_i)| + |f(x_i) - f(x)| <2 \varepsilon, \end{equation*}
    for some \(i\text{,}\) by the choice of \(\delta_{x_i}\text{.}\) Further
    \begin{equation*} \bigcup_{j \in B} (y_{i-1},y_i) \subseteq \bigcup_{k=1}^\infty I_k, \end{equation*}
    and so
    \begin{equation*} \sum_{j \in B} (y_i - y_{i-1}) < \varepsilon. \end{equation*}
    Let \(M = \sup_{x \in [a,b]}|f(x)|\text{.}\) Then
    \begin{equation*} \begin{aligned} O(f,P) =& \sum_{j=1}^m \sup_{x,y \in [y_{j-1},y_j]}|f(x) - f(y)|(y_i - y_{j-1}) \\ =& \sum_{j\in A}\sup_{x,y \in [y_{j-1},y_j]}|f(x) - f(y)|(y_i - y_{j-1})\\ &+ \sum_{j\in B}\sup_{x,y \in [y_{j-1},y_j]}|f(x) - f(y)|(y_i - y_{j-1})\\ <& 2\varepsilon \sum_{j\in A}(y_i - y_{j-1}) + 2M \sum_{j\in B}(y_i - y_{j-1})\\ <& 2\varepsilon(b-a) + 2M \varepsilon = 2\varepsilon(b-a + M). \end{aligned} \end{equation*}
    Hence \(f\) is Riemann integrable.
    🔗
    🔗

    Lemma 6.3.2.

    Let \(f\) be a bounded function on the closed interval \([a,b]\text{.}\) If \(f\) is Riemann integrable, then \(f\) is measurable.
    🔗
    🔗

    Proof.

    Let \(D = \{x \in [a,b] \colon f \text{ not continuous at }x\}\text{,}\) and let \(E = [a,b]\backslash D\text{.}\) Since \(f\) is continuous on \(E\text{,}\) we have that \(f|_E\) is a measurable function by Corollary 5.1.5. By Theorem 6.3.1, \(m(D) = 0\text{.}\) Since \(m\) is a complete measure on \([a,b]\text{,}\) \(f|_D\) is a measurable function. Thus \(f\) is measurable.
    🔗
    🔗
    We have defined the Lebesgue integral in terms of integrals of simple functions. The Riemann integral is usually defined in terms of Riemann sums. The following definition allows us to describe Riemann sums by integrals of simple functions.
    🔗

    Definition 6.3.3.

    A simple function \(\varphi\) on a closed interval \([a,b]\) is a step function if
    \begin{equation*} \varphi = \sum_{k=1}^n a_k \chi_{[x_{n-1},x_n]} \end{equation*}
    for some partition \(P = \{a=x_0 < x_1<\ldots<x_n = b\}\) of \([a,b]\text{.}\)
    🔗
    🔗
    Let \(f\) be a bounded function on \([a,b]\) and let \(P = \{a=x_0 < x_1<\ldots<x_n = b\}\) be a partition of \([a,b]\text{.}\) For \(1\leq k \leq n\text{,}\) let \(a_k = \inf_{x \in[x_{k-1},x_k]} f(x)\text{.}\) Then the lower Darboux sum of \(f\) with respect to \(P\) is
    \begin{equation*} L(f,P) := \sum_{k=1}^n a_k(x_{k-1} - x_k). \end{equation*}
    If we let \(\varphi\) be the step function \(\phi_P = \sum_{k=1}^n a_k \chi_{[x_{k-1},x_k]}\) then
    \begin{equation*} \int_{[a,b]} \phi_P \,dm = L(f,P). \end{equation*}
    Similarly, if \(b_k = \sup_{x \in[x_{k-1},x_k]} f(x)\text{.}\) Then the upper Darboux sum of \(f\) with respect to \(P\) is
    \begin{equation*} U(f,P) := \sum_{k=1}^n b_k(x_{k-1} - x_k). \end{equation*}
    If we let \(\psi\) be the step function \(\psi_P = \sum_{k=1}^n b_k \chi_{[x_{k-1},x_k]}\) then
    \begin{equation*} \int_{[a,b]} \psi_P \,dm = U(f,P). \end{equation*}
    That is, the upper and lower Riemann sums are equal to the integrals of step functions.
    🔗

    Theorem 6.3.4.

    Let \(f\) be a bounded function on a closed interval \([a,b]\text{.}\) If \(f\) is Riemann integrable then \(f\) is Lebesgue integrable and
    \begin{equation*} \mathrm{R}{\int}_a^b f = \int_{[a,b]}f\,dm. \end{equation*}
    🔗
    🔗

    Proof.

    Assume \(f\) is Riemann integrable. By Lemma 6.3.2, \(f\) is measurable. Let \(M\) be an upper bound for \(|f|\text{.}\) Then
    \begin{equation*} \int_{[a,b]}|f|\,dm \leq M m([a,b]) < \infty. \end{equation*}
    Thus \(f\) is Lebesgue integrable.
    🔗
    For each partition \(P\) let \(\phi_P\) be a step function such \(\phi_P\leq f\) and
    \begin{equation*} \int_{[a,b]}\phi_P\,dm = L(f,P), \end{equation*}
    and let \(\psi_P\) be a step function such \(f\leq\psi_P\) and
    \begin{equation*} \int_{[a,b]}\psi_P\,dm = U(f,P). \end{equation*}
    Note that such a step functions \(\phi_P\) and \(\psi_P\) exist by the argument preceding this theorem.
    🔗
    Since \(f\) is Riemann integrable we have that
    \begin{equation*} \mathrm{R}{\int}_a^b = \sup_P L(f,P) = \inf_P U(f,P). \end{equation*}
    Since, for every partition \(P\text{,}\) \(\phi_P \leq f \leq \psi_P\text{,}\) the monotonicity of Lebesgue integral tells us
    \begin{equation*} \begin{aligned} \sup_P L(f,P) = \sup_P \int_{[a,b]}\phi_P\,dm &\leq \int_{[a,b]} f\,dm \\ &\leq \sup_P \int_{[a,b]}\psi_P\,dm = \sup_P U(f,P). \end{aligned} \end{equation*}
    Hence \(\mathrm{R}{\int}_a^b f = \int_{[a,b]}f\,dm\text{.}\)
    🔗
    🔗

    Remark 6.3.5.

    Let \([a,b]\) be a closed interval. We have shown that the set of bounded Riemann integrable functions on \([a,b]\) is contained in the set of bounded Lebesgue integrable functions on \([a,b]\text{.}\) When \([a,b]\) is not a singleton (i.e. when \(a<b\)), this inclusion is strict. If \(A = \mathbb{Q} \cap [a,b]\) then \(\chi_A\) is a Lebesgue integrable function on \([a,b]\text{,}\) but \([a,b]\) is not Riemann integrable.
    🔗
    🔗
    The following example shows that the statements analogous to the Monotone Convergence Theorem and the Lebesgue Dominated Convergence Theorem for Riemann integration do not hold.
    🔗

    Example 6.3.6.

    Let \(X = [0,1]\) and let \(A = \mathbb{Q} \cap [0,1]\text{.}\) The set \(A\) is countable and so can be enumerated as
    \begin{equation*} A = \{a_1,a_2,\ldots\} \end{equation*}
    For each \(n\) let
    \begin{equation*} A_n = \{a_1,\ldots,a_n\}, \end{equation*}
    and let \(f_n = \chi_{A_n}\text{.}\) Then \((f_n)_n\) is an increasing sequence of non-negative Riemann-integrable functions which converge pointwise to \(\chi_A\text{.}\) The Riemann integral of each \(f_n\) is \(0\text{.}\) However, as noted in Example 1.1.7, \(\chi_A\) is not Riemann integrable.

    We do not have
    \begin{equation*} \lim_n \mathrm{R}{\int}_0^1f_n = \mathrm{R}{\int}_0^1 \chi_A \end{equation*}
    since \(\mathrm{R}{\int}_0^1 \chi_A\) is not defined. Of course, using Lebesgue integration, we get

    Indeed this is an easy calculation to do directly. Alternatively it follows from either the Monotone Convergence Theorem or the Lebesgue Dominated Convergence Theorem.

    Recall that Riemann integrals can be extended beyond closed intervals by improper Riemann integrals. That is we define
    \begin{equation*} \begin{aligned} \mathrm{R}{\int}_a^\infty f &= \lim_{b \rightarrow \infty}\mathrm{R}{\int}_a^b f, \\ \mathrm{R}{\int}_{-\infty}^b f &= \lim_{a \rightarrow -\infty}\mathrm{R}{\int}_a^b f,\text{ and} \\ \mathrm{R}{\int}_{-\infty}^\infty f &= \lim_{b \rightarrow \infty}\lim_{a \rightarrow -\infty}\mathrm{R}{\int}_a^b f \\ \end{aligned} \end{equation*}
    The following examples show that it is possible for a function \(f\) to have a finite improper Riemann integral but not be Lebesgue integrable.

    Remark 6.3.11.

    Example 6.3.7 and Example 6.3.9 highlight an important difference between Lebesgue integrals and improper Riemann integrals. Let \(f\) be a function on the non-negative real line \([0,\infty)\text{.}\) Then \(f\) has a finite improper Riemann integral if and only if \(f\) is Riemann integrable on every each interval \([n-1,n]\) and the series \(\sum_{n=1}^\infty \mathrm{R}{\int}_{n-1}^n f\text{.}\) Then
    \begin{equation*} \mathrm{R}{\int}_0^\infty f = \sum_{n=1}^\infty \mathrm{R}{\int}_{n-1}^n f = \sum_{n=1}^\infty \int_{[n-1,n)}f\,dm. \end{equation*}
    For Lebesgue integration, convergence of the series \(\sum_{k=1}^\infty \int_{[n-1,n)}f\,dm\) is not sufficient. If \(f\) is Lebesgue integrable on \([0,\infty)\) then
    \begin{equation*} \int_{[0,\infty)} f\,dm = \sum_{n=1}^\infty \int_{E_n} f\,dm \end{equation*}
    for any collection of disjoint measurable sets \(\{E_n\}_n\) with \(\bigcup_n E_n = [0,\infty)\text{.}\) Thus, reordering the collection \(\{E_n\}_n\) does not affect the value of
    \begin{equation*} \int_{[0,\infty)}f\,dm = \sum_{n=1}^\infty \int_{E_n} f\,dm. \end{equation*}
    Thus, the series \(\sum_{n=1}^\infty \int_{E_n} f\,dm\) is not only convergent, but absolutely convergent. In Example 6.3.7 and Example 6.3.9
    \begin{equation*} \sum_{n=1}^\infty \mathrm{R}{\int}_{n-1}^n f \text { and } \sum_{n=1}^\infty \mathrm{R}{\int}_{n-1}^n g \end{equation*}
    are conditionally convergent, not absolutely convergent.
