Let \((X,d)\) be a topological space. If \(A \subseteq X\text{,}\) the closure of \(A\text{,}\) denoted by \(\overline{A}\text{,}\) is the smallest closed set containing \(A\text{;}\) and the interior of \(A\text{,}\) denoted by \(A^\circ\text{,}\) is the largest open set contained in \(A\text{.}\) A set \(A \subseteq X\) is dense if \(\overline{A} = X\text{.}\) A set \(A\) is dense in \(X\) if \(\overline{A} = X\text{.}\)
