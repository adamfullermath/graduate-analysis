Definition B.2.2.

Let \((X,d)\) be a metric space. A set \(U \subseteq X\) is open if for all \(x \in X\) there exists \(\varepsilon \gt 0\) such that
\begin{equation*} \{ y\in X \colon d(x,y)\lt \varepsilon \} \subseteq U. \end{equation*}
A set \(F \subseteq X\) is closed if \(X \backslash F\) is open.
