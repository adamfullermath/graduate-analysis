Definition B.2.4.

A topology on a non-empty set \(X\) is a collection of subsets \(\tau\) of \(X\) with the properties
  1. \(\emptyset\text{,}\) \(X \in \tau\text{;}\)
    🔗
  2. if \(\mathcal{F}\) is a collection of sets in \(\tau\) then \(\bigcup_{F\in \mathcal{F}} F \in \tau\text{;}\)
    🔗
  3. if \(F_1, \ldots, F_n \in \tau\) then \(\bigcap_{i=1}^n F_i \in \tau\text{.}\)
    🔗
We call the elements of \(\tau\) open sets. If \(A\) is open, we call \(X\backslash A\) closed. We call \((X,\tau)\text{,}\) or simply \(X\) if the topology \(\tau\) is clear, a topological space.
