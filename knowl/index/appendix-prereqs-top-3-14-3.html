Definition B.1.11.

A set \(U \subseteq \bR^n\) is open if for all \(x \in U\) there exists \(\varepsilon \gt 0\) such that
\begin{equation*} \{y \in \bR^n \colon \|x-y\|_2\lt \varepsilon \} \subseteq U. \end{equation*}
A set \(F \subseteq \bR^n\) is closed if \(\bR^n \backslash F\) is open.
