Definition B.3.1.

Let \((X,d_X)\) and \((Y,d_Y)\) be two metric spaces, and let \(f \colon X \rightarrow Y\) be a function. The function \(f\) is continuous at a point \(x_0 \in X\) if for all \(\varepsilon \gt 0\) there exists a \(\delta \gt 0\) such that \(d_Y(f(x_0),f(y))\lt\varepsilon\) for all \(y \in X\) with \(d_X(x_0,y)\lt \delta.\) The function \(f\) is uniformly continuous if for all \(\varepsilon \gt 0\) there is a \(\delta \gt 0\) such that if \(x,y \in X\) and \(d_X(x,y) \lt \delta\) then \(d_Y(f(x),f(y))\lt \delta\text{.}\)
