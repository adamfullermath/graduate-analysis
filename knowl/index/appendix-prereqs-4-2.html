Definition A.2.1.

Two sets, \(A\) and \(B\) have the same cardinality if there is a bijective map
\begin{equation*} f \colon A \rightarrow B. \end{equation*}
A set \(A\) is called countable if \(A\) has finitely many elements, or if \(A\) has the same cardinality as the natural numbers \(\mathbb{N}\text{.}\) In the latter case we call \(A\) countably infinite. In the former, we say \(A\) has cardinality \(n\text{,}\) where \(n\) is the number of elements in \(A\text{.}\) If a set is not countable, we say it is uncountable.
