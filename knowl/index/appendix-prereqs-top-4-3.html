Definition B.2.1.

Let \(X\) be a non-empty set. A function \(d \colon X\times X \rightarrow \bR\) is a metric if
  1. \(d(x,y) \geq 0\) for all \(x,y \in X\text{,}\) and \(d(x,y)=0\) if and only if \(x=y\text{;}\)
    🔗
    🔗
  2. \(d(x,y) = d(y,x)\) for all \(x,y \in X\text{;}\) and
    🔗
    🔗
  3. \(d(x,y) \leq d(x,z) + d(z,y)\) for all \(x,y,z \in X\) (triangle inequality).
    🔗
    🔗
If \(d\) is a metric on \(X\text{,}\) the pair \((X,d)\) is called a metric space. When the metric \(d\) is clear, we often simply call \(X\) a metric space.
