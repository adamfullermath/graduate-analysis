A relation \(\sim\) on \(X\) is an equivalence relation if it satisfies the following conditions:
  1. \(x\sim x\) for all \(x\in X\) (\(\sim\) is reflexive);
    🔗
  2. \(x\sim y\) if and only if \(y\sim x\) (\(\sim\) is symmetric);
    🔗
  3. if \(x\sim y\) an \(y\sim z\) then \(x\sim z\) (\(\sim\) is transitive).
    🔗
Let \(\sim\) be an equivalence relation on \(X\text{.}\) For \(x\in X\text{,}\) the equivalence class of \(x\) is
\begin{equation*} [x] = \{y\in X \colon x\sim y\}. \end{equation*}
