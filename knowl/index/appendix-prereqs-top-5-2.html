Recall the following definitions from a first course in real analysis. Let \(A \subseteq \bR\) be a non-empty set and let \(f \colon A \rightarrow \bR\) be a function. The function \(f\) is continuous at a point \(x_0 \in A\) if for all \(\varepsilon \gt 0\) there exists a \(\delta \gt 0\) such that \(|f(x_0)-f(y)|\lt\varepsilon\) for all \(y \in A\) with \(|x_0-y|\lt \delta.\) The function \(f\) is continuous if \(f\) is continuous at every point in \(A\text{.}\) The function \(f\) is uniformly continuous if for all \(\varepsilon \gt 0\) there is a \(\delta \gt 0\) such that if \(x,y \in A\) and \(|x-y| \lt \delta\) then \(|f(x) - f(y)|\lt \delta\text{.}\) Note that uniform continuity is a stronger condition than continuity.
