A choice function \(f\) on \(\mathcal{F}\) is a mapping
\begin{equation*} f \colon \mathcal{F} \rightarrow \bigcup_{F\in\mathcal{F}} F, \end{equation*}
such that \(f(F) \in F\) for all \(F\in \mathcal{F}\text{.}\) That is, \(f\) chooses an element from each set \(F \in \mathcal{F}\text{.}\) The axiom of choice states that given any collection of non-empty sets a choice function always exists.
