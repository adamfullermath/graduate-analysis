Definition 3.2.7.

Let \(S = (S_1,\ldots,S_m)\) be a family of similitudes on \(\bR^n\text{.}\) A non-empty open set \(U \subseteq \bR^n\) is a separating set for \(S\) if
\begin{equation*} S(U) \subseteq U,\ \text{ and } \{S_k(U)\}_{k=1}^m \text{ are pairwise disjoint}. \end{equation*}
