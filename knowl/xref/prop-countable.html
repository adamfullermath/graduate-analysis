Proposition A.2.6.

  1. If \(A\) is a countable set, and \(B \subseteq A\) then \(B\) is countable.
    🔗
  2. If \(\{A_i\}_{i \in I}\) is a countable collection of countable sets, then \(\bigcup_{i\in I} A_i\) is countable.
    🔗
  3. If \(\{A_i\}_{i=1}^n\) is a finite collection of countable sets, then the cartesian product \(\prod_{i=1}^n A_i\) is countable.
    🔗
🔗
🔗

Proof.

If \(B \subseteq A\) and \(A\) is finite, then \(B\) is finite and hence countable. If \(A\) is countably infinite, then there is a bijection \(f \colon A \rightarrow \bN\text{.}\) Using \(f\text{,}\) we can identify \(A\) with \(\bN\text{,}\) and hence identify \(B\) with a subset of \(\bN\text{.}\) If \(B\) is finite, then \(B\) is countable. Otherwise, \(B\) is an inifinite subset of \(\bN\text{.}\) Let \(b_1\) be the smallest element of \(B\text{,}\) let \(b_2\) be the smallest element of \(B \backslash \{b_1\}\text{,}\) and so on. The map \(g \colon B \rightarrow \bN\) defined by \(g(b_n) = n\) is a bijection from \(B\) to \(\bN\text{.}\)
🔗
Let \(\{A_i\}_{i \in I}\) be a countable collection of finite sets. We will further assume that the sets \(A_i\) are disjoint. The general case can be handled by replacing each \(A_i\) with \(A_i \backslash \bigcup_{j=1}^{i-1} A_j\text{.}\) Without loss of generality, we can assume that \(I = \bN\text{.}\) Let \(A = \bigcup_{i\in I} A_i\text{.}\) Let \(n_i\) be the number of elements in \(A_i\) for each \(i \in \bN.\) We can define a bijection from \(A\) to \(\bN\) by sending the elements of \(A_1\) to the first \(n_1\) natural numbers, the elements of \(A_2\) to the next \(n_2\) natural numbers, and so on. Hence \(A\) is countable.
🔗
We will now show that \(\bN \times \bN\) is countable. For each \(k \in \bN\) let
\begin{equation*} A_k = \{(n,m) \in \bN \times \bN \colon n+m = k\}. \end{equation*}
Then \(\bN \times \bN = \bigcup_{k=1}^\infty A_k\) is a countable union of finite sets. Thus, by the above argument, \(\bN \times \bN\) is countable.
🔗
Now, let \(\{A_i\}_{i \in I}\) be a countable collection of countably infinite sets. Let \(A = \bigcup_{i\in I} A_i\text{.}\) We will show that \(A\) is countable. We will again assume that the sets \(A_i\) are disjoint and that \(I = \bN\text{.}\) Let \(f_i \colon A_i \rightarrow \bN\) be a bijection for each \(i\in I\text{.}\) Then the map \(f(a) = (f_i(a), i)\) for \(a \in A_i\) is a bijection from \(A\) to \(\bN \times \bN\text{.}\) Thus \(A\) is countable.
🔗
Finally, since \(\bN \times \bN\) is countable, we can show by induction that \(\prod_{i=1}^n A_i\) is countable for any finite collection of countable sets \(\{A_i\}_{i=1}^n\text{.}\)
