Proposition 2.2.1.

Let \((X,\mathcal{M},\mu)\) be a measure space. Then the following hold
  1. (Monotonicity) If \(A, B \in \mathcal{M}\) with \(B \subseteq A\text{,}\) then \(\mu(B)\leq \mu(A)\text{;}\)
    🔗
  2. (Excision) If \(A,B \in \mathcal{M}\) with \(B\subseteq A\) and \(\mu(A)<\infty\text{,}\) then \(\mu(A \backslash B) = \mu(A) - \mu(B)\text{;}\)
    🔗
  3. (Countable monotonicity) If \(\{E_k\}_{k=1}^\infty\) is a countable collection of measurable sets, and \(E\) is a measurable set such that \(E \subseteq \bigcup_{k=1}^\infty E_k\text{,}\) then \(\mu(E) \leq \sum_{k=1}^\infty \mu(E_k).\)
    🔗
🔗
🔗

Proof.

Take \(A, B \in \mathcal{M}\) with \(B \subseteq A\text{.}\) Note we can write \(A\) as a disjoint union
\begin{equation*} A = B \cup (A \backslash B). \end{equation*}
Thus
\begin{equation} \mu(A) = \mu(B) + \mu(A \backslash B).\tag{2.1} \end{equation}
Thus, \(\mu(B) \leq \mu(A)\text{.}\) If \(\mu(A)<\infty\text{,}\) then it follows that \(\mu(B) < \infty\) and \(\mu(A\backslash B) < \infty\text{.}\) Hence, it follows from (2.1) that
 1 
That \(\mu(A)\) is finite is imporant here. Otherwise we could be looking at \(\infty - \infty\text{,}\) which is undefined.
\begin{equation*} \mu(A\backslash B) = \mu(A) - \mu(B). \end{equation*}
Now let \(\{E_k\}_{k=1}^\infty\) be a countable collection of sets in \(\mathcal{M}\text{.}\) Let \(A_1 = E_1\text{.}\) Let \(A_2 = E_2 \backslash A_1\text{.}\) Continuing in this way, we let
\begin{equation*} A_k = E_k \backslash \bigcup_{n=1}^{k-1} A_n. \end{equation*}
In this way, we get a countable family \(\{A_k\}_{k=1}^\infty\) of disjoint measurable sets, which satisfies
\begin{equation*} \bigcup_{k=1}^\infty A_k = \bigcup_{k=1}^\infty E_k, \end{equation*}
and \(\mu(A_k) \leq \mu(E_k)\) for each \(k\text{.}\) Thus, if \(E \subseteq \bigcup_k E_k\) we have
\begin{equation*} \begin{aligned} \mu(E) &\leq \mu\left( \bigcup_{k=1}^n E_k \right) \\ &= \mu\left( \bigcup_{k=1}^n A_k \right) \\ &= \sum_{k=1}^\infty \mu(A_k) \\ &\leq \sum_{k=1}^\infty \mu(E_k). \end{aligned} \end{equation*}
