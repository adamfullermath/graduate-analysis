Theorem 2.2.2. Continuity of measure.

Let \((X,\mathcal{M},\mu)\) be a measure space.
  1. If \(\{A_k\}_{k=1}^\infty\) is a countable collection of measurable sets satisfying \(A_k \subseteq A_{k+1}\) (i.e. \(\{A_k\}_k\) ascending measurable sets), then
    \begin{equation*} \mu\left(\bigcup_{k=1}^\infty A_k \right) = \lim_{k\rightarrow \infty} \mu(A_k). \end{equation*}
    🔗
  2. If \(\{B_k\}_{k=1}^\infty\) is a countable collection of measurable sets satisfying \(B_{k+1} \subseteq B_{k}\) (i.e. \(\{B_k\}_k\) descending measurable sets) and \(\mu(B_1)<\infty\text{,}\) then
    \begin{equation*} \mu\left(\bigcap_{k=1}^\infty B_k \right) = \lim_{k\rightarrow \infty} \mu(B_k). \end{equation*}
    🔗
🔗
🔗

Proof.

Let \(\{A_k\}_{k=1}^\infty\) be an countable collection of ascending measurable sets, and let \(A = \bigcup_k A_k\text{.}\) If \(\mu(A_{k_0}) = \infty\) for some index \(k_0\text{,}\) then \(\mu(A) = \infty\) since \(A_{k_0} \subseteq A\) (by the monotonicity of \(\mu\)). Hence
\begin{equation*} \infty = \mu(A) = \mu(A_{k_0}) = \lim_k \mu(A_k). \end{equation*}
Assume now that \(\mu(A_k) < \infty\) for all \(k\text{.}\) Let \(B_1 = A_1\) and let
\begin{equation*} B_k = A_k \backslash A_{k-1}. \end{equation*}
Then \(\{B_k\}_{k=1}^\infty\) is a countable collection of disjoint measurable sets satisfying
\begin{equation*} \begin{aligned} A_k = \bigcup_{m=1}^k B_m. \end{aligned} \end{equation*}
Hence \(A\) is the disjoint union \(A = \bigcup_k B_k\text{.}\) Thus
\begin{equation*} \begin{aligned} \lim_{k} \mu(A_k) &= \lim_k \mu\left(\bigcup_{m=1}^k B_k\right) \\ &= \lim_k \sum_{m=1}^k \mu(B_m) \\ &= \sum_{m=1}^\infty \mu(B_m)\\ &= \mu(A). \end{aligned} \end{equation*}
Thus (i) holds.
🔗
Now assume \(\{B_k\}_{k=1}^\infty\) is a descending collection of measurable sets, with \(\mu(B_1)<\infty\text{.}\) For each \(k\text{,}\) let \(D_k = B_1 \backslash B_k\text{.}\) Then \(\{D_k\}_{k=1}^\infty\) is an ascending sequence of measurable sets. By part (i), we have that
\begin{equation} \begin{aligned} \mu\left( \bigcup_k D_k \right) \amp = \lim_k \mu(D_k) \\ \amp = \lim_k [\mu(B_1) - \mu(B_k)] = \mu(B_1) - \lim_k \mu(B_k). \end{aligned}\tag{2.2} \end{equation}
Note that we have used the fact that \(\mu(B_1)<\infty\) in order to use the excision property in (2.2). By De Morgan’s identities
\begin{equation*} \bigcup_k D_k = \bigcup_k (B_1 \backslash B_k) = B_1 \backslash \bigcap_k B_k. \end{equation*}
Hence
\begin{equation} \mu\left(\bigcup_k D_k\right) = \mu(B_1) - \mu\left(\bigcap_k B_k \right).\tag{2.3} \end{equation}
Combining (2.2) and (2.3) we get
\begin{equation*} \mu \left(\bigcap_k B_k \right) = \lim_k \mu(B_k). \end{equation*}
