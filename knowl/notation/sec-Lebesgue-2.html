We will now apply the Carathéodory-Hahn Theorem, Theorem 2.3.16, to define the promised Lebesgue measure. Our goal is to extend the length function \(\ell\) to a measure. In Example 2.3.11 (see Exercise 2.4.13) we saw three different semirings of intervals. We will show now that the length function \(\ell\) on intervals defines a premeasure. Recall that \(\ell\) is defined, for real numbers \(a\leq b\) by
\begin{align*} \ell((a,b)) \amp = \ell([a,b)) = \ell((a,b]) = \ell([a,b]) = b-a, \text{ and}\\ \ell((-\infty,b)) \amp = \ell((-\infty,b)) = \ell((a,\infty)) = \ell([a,\infty)) = \ell(\bR)=\infty. \end{align*}
